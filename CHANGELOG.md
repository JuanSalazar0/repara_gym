## How to Update This Changelog

### For Contributors

When making changes, update the appropriate section under `[Unreleased]`:

- **Added** for new features
- **Changed** for changes in existing functionality
- **Deprecated** for soon-to-be removed features
- **Removed** for now removed features
- **Fixed** for any bug fixes
- **Security** in case of vulnerabilities

### For Maintainers

When releasing a new version:

1. Move all items from `[Unreleased]` to the new version section
2. Update the version number and date
3. Add a new `[Unreleased]` section at the top
4. Commit and tag the release

### Example

```markdown
## [1.1.0] - 2024-02-XX

### Added
- New feature X
- New feature Y

### Changed
- Updated component Z

### Fixed
- Bug in feature A

## [Unreleased]

### Added
- N/A

### Changed
- N/A

### Fixed
- N/A
```
